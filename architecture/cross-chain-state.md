# Cross-Chain ANT State

## Overview

The BITY Protocol supports Autonomous Node Tokens (ANTs) across Ethereum and Solana.

Each ANT maintains a stable NFT identity while protocol state evolves dynamically.

---

# Stable Identity Layer

The identity layer remains chain-native and stable.

## Ethereum
- ERC-721 identity
- ownership
- provenance
- collection membership

## Solana
- Metaplex NFT identity
- mint ownership
- collection verification
- provenance

---

# Dynamic Protocol State

The BITY Protocol controls dynamic node state.

Dynamic state includes:
- augmentation
- CRS scoring
- AI configuration
- permissions
- lineage
- proliferation
- node capabilities
- protocol participation
