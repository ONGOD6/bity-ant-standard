# ANT Augmentation Layer

## Overview

The augmentation layer defines how Autonomous Node Tokens evolve within the BITY Protocol.

Augmentation is the process of expanding an ANT’s protocol state, intelligence capabilities, permissions, participation history, and operational behaviors over time.

---

# Core Principle

The NFT identity remains stable while augmentation state evolves dynamically.

Stable:
- token identity
- provenance
- ownership

Dynamic:
- augmentation level
- CRS score
- node capabilities
- permissions
- AI configuration
- lineage state
- protocol participation

---

# Augmentation Sources

ANTs may augment through:

- prediction participation
- CRS accumulation
- driver activity
- protocol engagement
- AI training participation
- future node modes
- verified contribution systems

---

# Augmentation States

Example augmentation lifecycle:

1. Base
2. Training
3. Augmenting
4. Evolved
5. Autonomous

The BITY Protocol may expand or modify augmentation stages over time.

---

# Dynamic Metadata

The augmentation layer may update:

- visuals
- metadata
- protocol traits
- node capabilities
- displayed CRS
- lineage references

Dynamic metadata signaling on Ethereum may use:
- ERC-4906

# Cross-Chain Augmentation

Ethereum and Solana ANTs both resolve into the same augmentation state model.

Ethereum:
- ERC-721 ANT identity

Solana:
- Metaplex ANT identity

Both chains:
- share augmentation logic
- share CRS interpretation
- share protocol participation state
