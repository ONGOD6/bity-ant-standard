# ANT Standard

## Autonomous Node Token

ANT (Autonomous Node Token) is the core first NFT-native node architecture of the BITY Protocol.

ANTs function as autonomous protocol-native node entities capable of:

- dynamic augmentation
- CRS participation
- AI configuration
- lineage evolution
- cross-chain operation
- node-mode participation

# Ethereum Stack

- ERC-721
- ERC-4906
- ERC-8004
- Optional ERC-6551

# Solana Stack

- Metaplex DAS
- PDA-based protocol state accounts
- Dynamic metadata architecture

---

# Core Principle

The NFT identity remains stable while the protocol state evolves dynamically.

Stable identity:
- token id
- provenance
- ownership

Dynamic state:
- augmentation
- CRS
- AI capabilities
- permissions
- lineage
- metadata evolution

---

# BITY Protocol

The BITY Protocol resolves augmentation, CRS, lineage, and autonomous node state across supported chains.
